# Fever — structured workup (adult, CDS reference)

## Immediate history
- Onset, pattern, travel, sick contacts, animal exposure
- Immunosuppression, splenectomy, pregnancy, devices (lines, prosthetics)
- Focused review: respiratory, urinary, abdominal, skin/soft tissue, CNS

## Examination priorities
- Full vitals including orthostatics if tolerated
- Skin (petechiae, cellulitis), HEENT, lungs, abdomen, GU if indicated
- Neurologic if altered or headache

## Initial tests (adapt locally)
- CBC, CMP, lactate
- Blood cultures ×2 before antibiotics if sepsis suspected
- Urinalysis / urine culture
- Chest X-ray if respiratory symptoms
- Pregnancy test when applicable

## High-risk patterns
| Pattern | Consider |
|---------|----------|
| Petechial rash + fever | Meningococcemia — immediate antibiotics |
| Post-procedure / line fever | Line infection, endocarditis |
| RLQ pain + fever | Appendicitis, PID, diverticulitis |
| Flank pain + fever | Pyelonephritis, stone with infection |
| Jaundice + fever | Cholangitis (Charcot triad) |
| Immunocompromised + fever | Broad differential; low threshold for admit |

## Antibiotic stewardship
Match spectrum to focus; reassess at 48–72h with cultures. Document source control needs (drainage, removal of infected hardware).

## Citations to verify locally
WHO sepsis guidance; Surviving Sepsis Campaign (latest edition); IDSA fever and neutropenia guidelines where applicable.
